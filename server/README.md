# Сервер Device Market 0.1

Требуется Node.js 20 или новее. Внешних зависимостей нет.

## Запуск на Windows

Дважды нажмите `start.cmd` либо выполните `npm start` в этой папке.
Откройте http://localhost:3000 . Остановка: Ctrl+C в окне сервера.

1. Зарегистрируйте устройство слева, задав длительность.
2. Вставьте выданный код справа (можно в другом окне браузера).
3. Нажмите «Запросить подключение», затем «Разрешить» у владельца.
4. Проверьте «Немедленно отключить». Гость увидит завершение при следующем обновлении (до 2 секунд).

Для двух устройств в своей локальной сети запустите из PowerShell:

```powershell
$env:HOST="0.0.0.0"
npm start
```

На втором устройстве откройте `http://<локальный-IP-владельца>:3000`. Если Windows спросит, разрешите Node.js доступ в частной сети. Это режим разработки без TLS, не для публикации в интернет. По умолчанию сервер слушает только этот ПК.

## Реализовано

- Регистрация устройства, одноразовый случайный код на 10 минут.
- Раздельные секреты владельца и гостя, подтверждение только владельцем.
- Один незавершённый запрос/сеанс на устройство.
- Ограничение времени на сервере, остановка обеими сторонами.
- Удаление устройства при отсутствии опроса владельца более 2 минут.
- Ограничение попыток ввода кода, размера запросов и числа устройств.

Вся информация находится в памяти и сбрасывается при перезапуске. Токены страницы хранятся в sessionStorage. Не передавайте токен владельца гостю.

## Ещё не реализовано

Передача звука и ввода; TURN; связь с Windows-приложением и сайтом GitHub Pages; аккаунты; проверка характеристик; журнал файлов; запись и откат.

Показ экрана добавлен через WebRTC. После подтверждения гостя владелец нажимает «Выбрать экран и начать передачу» и разрешает захват в браузере. Для проверки используйте отдельное окно инкогнито для гостя на localhost. Для выбора экрана на другом ПК необходим HTTPS (обычный HTTP по LAN-IP не подходит). Без TURN соединение между разными сетями не гарантируется. Проверены серверные разрешения и обмен SDP; визуальная передача в браузере требует ручной проверки.

Публичное размещение требует HTTPS/WSS, постоянного хранилища, аутентификации пользователей и настроенного разрешённого origin. Текущая страница работает только с API своего сервера.

Проверки: `npm test`.
