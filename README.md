# Device Market

Прототип площадки бесплатного удалённого доступа к устройствам.

- [Сайт каталога](https://sherbakovyan7-bit.github.io/device-market/)
- [Windows-приложение v0.1](https://github.com/sherbakovyan7-bit/device-market/releases/tag/v0.1)

## Сервер и показ экрана

Скачайте репозиторий через **Code → Download ZIP**, распакуйте и запустите `server/start.cmd`. Требуется Node.js 20 или новее. Откройте http://localhost:3000 .

Владелец регистрирует устройство и задаёт время. Гость вводит одноразовый код. Владелец подтверждает запрос, затем нажимает **«Выбрать экран и начать передачу»** и разрешает захват в браузере.

Для локальной проверки откройте гостя в отдельном окне инкогнито. Работает передача видео через WebRTC без управления мышью и клавиатурой. Серверные проверки обмена SDP и прав доступа пройдены; сквозной показ видео требует ручной проверки.

Подробности: [server/README.md](server/README.md).

## Текущее состояние

Каталог GitHub Pages хранит объявления только в браузере. Windows-приложение определяет характеристики и моделирует сеансы локально. Сервер работает отдельно: эти три части ещё не интегрированы.

GitHub Pages не запускает Node.js. Для подключения через интернет нужны отдельный хостинг сервера, HTTPS и при необходимости TURN. Запись экрана, журнал файлов, откат и удалённый ввод не реализованы.
